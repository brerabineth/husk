# fixtures — synthetic elf stubs, harmless by construction

every binary here exists so analysts can exercise husk without touching
real malware. none of them perform system calls beyond returning. none
of them contact anything. the imposter declares symbols it never calls;
the packer carries a deterministic random blob generated by a fixed
seed; the hollower and the shrouded are byte-level mangles of the
benign binary (see tools/mangle.py).

| file | what it pretends to be | verdict |
|---|---|---|
| benign.elf | honest dynamic binary | clean 0 |
| benign_static.elf | statically linked glibc | clean 0 |
| shrouded.elf | section-name index destroyed | suspicious 15 |
| hollower.elf | section map erased (sstrip-style) | suspicious 18 |
| ioring.elf | io_uring imports, nothing else | suspicious 20 |
| packed.elf | upx magic + 8.0 entropy blob | malicious 46 |
| imposter.elf | twenty stacked indicators | critical 100 |
| decoy.txt | not an elf at all | skipped |

rebuild (linux, gcc):

    gcc -O2 -Wall -fstack-protector-strong -o bin/benign.elf src/benign.c
    gcc -O2 -Wall -fstack-protector-strong -static -o bin/benign_static.elf src/benign_static.c
    gcc -O2 -Wall -shared -fPIC -o bin/imposter.elf src/imposter.c
    gcc -O2 -Wall -shared -fPIC -o bin/ioring.elf src/ioring.c
    gcc -O2 -Wall -shared -fPIC -s -Wl,-z,execstack -o bin/packed.elf src/packed.c
    python3 ../tools/gen_blob.py   # writes src/packed_blob.h
    python3 ../tools/mangle.py     # rewrites hollower.elf + shrouded.elf
